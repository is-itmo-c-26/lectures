## Задача

Необходимо реализовать функцию `IsTwiceSequence`, которая в качестве обязательных аргументов принимает два итератора (корректный диапазон итераторов) на последовательность произвольного типа. Итератор отвечает требованиям однонаправленного итератора. В качествее результата возвращает `bool`.
`True` в случае если последовательно представляет из себя удвоенную подпоследовательность, `false` -  в противоположном.

Функция должна быть максимально обобщённой и учитывать всевозможные краевые случаи.

## Примеры

1. Для строки  `"abcdabcd"` -> `true`
2. Для строки  `"abcdabdc"` -> `false`
3. Для массива `{1,2,3,4,1,2,3,4}` -> `true`
4. Для вектора `{true, false, true}` -> `false`


## Ограничения
