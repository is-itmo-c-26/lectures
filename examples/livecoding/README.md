Страницы с условиями находятся в `livecoding/`. В опубликованных условиях исправлены очевидные опечатки и убраны ссылки на устаревшие формы сдачи. Оригинальные README сохранены в каталогах заданий.

ZIP в `assets/livecoding/` содержит все файлы соответствующего каталога в папке с его именем, без Git-метаданных. При обновлении исходников обновляйте и ZIP; текст кода на страницах берётся непосредственно из файлов через Quarto include.
