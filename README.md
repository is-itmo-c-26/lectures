# Основы программирования на C++

Основной репозиторий конспектов, слайдов и примеров кода курса.

## Структура

```
lectures/00-introduction.md     лекция: и страница сайта, и слайды
articles/01-setup.md            статья: только страница сайта
articles/01-setup-macos.md      её продолжение: гайд под систему
videos/index.md                 видеоматериалы курса
livecoding/index.md             архив заданий livecoding
examples/livecoding/<год-семестр>/ исходные заготовки заданий
assets/livecoding/              ZIP-архивы заданий для скачивания
assets/<материал>/              картинки материала
examples/<материал>/            исходники примеров кода
```

Лекции лежат в `lectures/` и собираются в двух видах: как страница конспекта и как Reveal.js-презентация. Статьи лежат в `articles/`, видео — в `videos/`, архив livecoding — в `livecoding/`; эти разделы собираются только как страницы сайта.

## Локальный просмотр

1. Установите Quarto и рекомендуемое расширение `Quarto` для VS Code.
2. Откройте эту папку в VS Code.
3. Выполните:

   ```sh
   quarto preview --to html
   ```

Собрать сайт целиком, без запуска сервера:

```sh
quarto render --to html
```

Результат появится в `_site/`, открывать `_site/index.html`.

## Слайды

Собрать все лекции как Reveal.js-презентации:

```sh
quarto render --profile slides --to revealjs
```

Собрать только одну лекцию:

```sh
quarto render lectures/00-introduction.md --profile slides --to revealjs
```

Результат появится в `_site/slides/lectures/`. Статьи в этот профиль не попадают.

## Новая статья

1. Создайте `articles/<номер>-<имя>.md` и укажите в заголовке `title`, `description` и авторов:

   ```yaml
   ---
   title: "Название статьи"
   description: "Одно предложение о чём это"
   author:
     - name: "Имя автора"
       url: https://t.me/nickname
   page-navigation: false
   ---
   ```

2. Картинки положите в `assets/articles/<номер>-<имя>/`, примеры кода — в `examples/articles/<номер>-<имя>/`. Из статьи на них ссылаются через `../assets/...` и `../examples/...`.
3. Добавьте статью в `_quarto.yml` в панель `articles` (раздел `Статьи`) и в список на `index.md`. В панель `lectures` статьи не добавляются: тогда стрелки «предыдущая / следующая» не будут перекидывать читателя с лекции на статью.

## Архив livecoding

Условия прошлых лет находятся в `livecoding/<год>-<autumn|spring>.md`. Год — календарный год проведения: например, весна курса `is-itmo-c-25` — это `2026-spring`.

Исходные файлы хранятся без изменений в `examples/livecoding/`, а ZIP для скачивания — в `assets/livecoding/`. Репозитории и точные коммиты записаны в `examples/livecoding/README.md`. Код на страницах подключается через `include`; после обновления исходников нужно обновить соответствующий ZIP. Старые заготовки могут содержать предупреждения или не компилироваться до реализации задания — это поясняется на страницах.

Новое задание добавляется в каталог на `livecoding/index.md` и в отдельную боковую панель `livecoding` в `_quarto.yml`. В профиль слайдов задания не включаются.

## Публикация

В настройках репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**. После этого каждый push в ветку `main` будет пересобирать и публиковать конспекты и презентации.
